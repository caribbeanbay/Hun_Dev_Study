# 🧑‍💻 Hun_Dev_Study

> 코딩테스트 문제 풀이 & 알고리즘 학습 기록

## 📌 목표
- 다양한 알고리즘 문제를 풀며 문제 해결 능력 향상
- Python → C++ → Java → C 순으로 언어 확장
- 4L 회고를 통한 꾸준한 성장 기록

## 🗂️ 구조
\```
Hun_Dev_Study/
├── Python/
│   ├── Level1/
│   │   └── 문제이름/
│   │       ├── problem.md
│   │       ├── solution.py
│   │       └── 4L.md
│   └── Level2/ ~ Level5/
├── Cpp/
├── Java/
└── C/
\```
