# 4L 회고 - [PCCP 기출문제 1번 - 동영상 재생기]

## 👍 Liked (좋았던 점)
- TODO list를 작성하여서 문제를 이해하고자 한 부분이 좋았다.
- 클로드가 작성해준 코드를 분석하면서 머리 속으로 하나 하나 어떻게 동작하는지 예상하면서 이해한 부분이 좋았다.

## 📚 Learned (배운 것)
- 조건부를 하나씩 정확하게 처리하기 위해서 TODO list를 작성하는 것.

## 😅 Lacked (부족했던 점)
- 클로드의 도움을 받기 전에 문제를 스스로 파악하고 정리하는 것이 중요한데, 무작정 클로드에 넣어서 진행을 해보니 이해하는데 어려움이 있었다.

## 🔥 Longed For (앞으로 할 것)
- 문제를 스스로 읽고 정확하게 파악한 후에 노션(문제 설명, 문제 조건부, TODO list, code)에 작성 후, 클로드를 사용하여 부족한 점을 채우고 클로드가 작성한 코드를 정확하게 분석하기 - 다음 문제부터 적용.
