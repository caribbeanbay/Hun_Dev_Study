# 4L 회고 - 노란불_신호등

## 👍 Liked (좋았던 점)
- GitHub 레포 구조를 처음부터 체계적으로 잡은 것이 만족스러웠다
- 브랜치 전략(main / develop)을 세우고 시작한 것이 좋았다

## 📚 Learned (배운 것)
- GitHub Flow 및 develop 브랜치 전략
- LCM을 활용해 탐색 범위를 줄이는 Brute Force 접근법
- `(t-1) % (G+Y+R)` 로 신호등 상태를 판별하는 방법

## 😅 Lacked (부족했던 점)
- 풀이를 스스로 고민하지 못하고 클로드의 도움을 많이 받았다
- Git 세팅에 시간이 너무 많이 걸렸다

## 🔥 Longed For (앞으로 할 것)
- Git 커밋 메시지 컨벤션을 습관화하기
- 다음 문제부터는 클로드와 함께 힌트 단계별로 풀이를 진행하며 스스로 생각하는 습관 기르기
